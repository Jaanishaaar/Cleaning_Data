# Cleaning_Data
Using power query to Clean Data
----------------------------------:-
The dataset includes common data-quality issues such as:

1. Missing values (blank cells)
2. Duplicate-style entries
3. Leading/trailing spaces
4. Mixed text casing (UPPERCASE, lowercase, Proper Case)
5. Invalid email formats
6. Inconsistent date formats
7. Negative and missing sales values
8. Inconsistent category names
9. Null values
--------------------------------
Suggested Excel cleaning tasks:-

1. Remove leading/trailing spaces (TRIM)
2. Standardize text case (PROPER, UPPER, LOWER)
3. Handle missing values
4. Validate email addresses
5. Convert dates to a single format
6. Identify duplicates
7. Clean currency values
8. Detect outliers in Sales
